# 长期训练计划、系统提醒与桌面小组件

## 设定与打卡

首页保留四个运动入口，下面进入“长期训练计划”。每个项目可设一个进行中或暂停的计划，也可以完全不设计划自由打卡。默认腹肌训练100天，可选30／150天或输入自定天数，也可直接选结束日期；起始当天算第1天。

重复安排支持每天、每周（多选星期）、每月、每年及自定间隔，例如每2周。每月可按起始日、月末或同序号星期；不存在的日期会跳过。时间按创建计划时的时区执行。调整安排从明天生效，历史安排不改写。

打卡时可选关联计划或“不关联计划”。同一计划同一天多次打卡只算一个训练日，休息日额外训练也算实际训练日。旧记录不自动归入新计划。报告可筛选全部、自由打卡或指定计划，网页Excel导出也跟随计划筛选。

## 100天之后

阶段到站后显示“继续到110天”“继续到120天”，也可自定更长的总目标。续期复用原计划，保留起始日、全部打卡、累计训练天数和阶段历史，不从第1天重开。系统生成的计划名称会随目标更新。

“计划第100天”表示已走过的计划日历天数，“已训练多少天”表示实际打卡的不同日期，“连续完成多少个训练日”按重复安排计算。休息与暂停不会中断连续训练；漏掉过去的应训练日才中断。因此阶段结束不等于宣称已经训练满100次。

暂停时停止提醒，恢复时结束日期按暂停天数顺延；若今天已经训练，暂停从明天算起。也可结束计划，保留记录，之后仍可续期；隐藏已结束计划不会删除训练记录。

## iPhone系统通知

在计划中开启“系统提醒”，首次使用允许系统通知；拒绝后可在计划页进入系统设置开启。完成当天打卡后取消当天尚未触发的提醒。点击通知进入对应训练打卡。

提醒使用iPhone本地系统通知，无需额外APNs服务，App关闭后系统仍可发送已经排好的提醒。为遵守系统待发送数量限制，最多安排最近60条；计划页显示已排条数及覆盖日期。每次打开App或打卡会续排。多个计划共用容量，不能保证数月不打开App仍持续收到全部提醒。

网页调整计划后，需要打开手机App联网同步，才能更新该手机已经排好的通知。通知展示还受系统权限、专注模式等设置影响。

## iPhone桌面小组件（iOS17及以上）

1. 安装更新后的App，在计划页点击“连接桌面小组件”，连接码会自动复制。
2. 长按iPhone主屏幕空白处，添加dailyRep的“健身坚持”小组件，可选小号或中号。
3. 长按小组件，选择编辑，将连接码粘贴到设置中。
4. 小组件显示实际训练天数、目标进度及今日状态，点击进入对应计划。首次设置需要联网。

连接码为12位随机十六进制，只能读取这一个计划的进度，不能登录、改数据或看照片。重置连接码会让旧码失效，已有小组件需重新填写。小组件缓存上次结果供断网展示；刷新由iOS调度，不能保证即时更新。App同步后会请求系统刷新。

## 更新安装与开发

这次新增了本地通知原生模块和WidgetKit扩展，旧手机安装包不会自行增加功能。当前工作目录已经生成并编译新工程；在Xcode打开 `ios/dailyRep.xcworkspace`，检查主App与DailyRepWidget扩展选择同一Team，选择iPhone后Run重新安装。脱离电脑使用请保持Release配置。

全新克隆需先运行 `npm ci`、`npx expo prebuild --platform ios --no-install`，再进入ios运行 `pod install`，最后打开workspace。配置插件可重复执行，保留主App签名设置；组件扩展要求iOS17，主App仍为iOS15.1。Expo Go不包含此次自定义原生模块。

构建通过不等于已经在真机确认通知送达与小组件显示；这两项需要安装后授权并在自己的iPhone添加组件。
